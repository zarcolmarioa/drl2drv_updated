WHY THIS SET
  Chosen after test_edit_levels_v5.py, run 4aa278d54d (committed as
  v5/stimulus_levels_data/4aa278d54d/), and a visual check of its
  viewer. Method A4_haze_cc_rgb: contrast down with v4's brightness-
  equated haze (haze_eq), contrast up with the same blend run backwards
  on RGB (v4's m_contrast_up, 'dehaze_rgb'), and at every contrast level
  a chroma factor that restores the scene's mean saturation, so the
  contrast levels leave saturation unchanged. Colour: v4's CIELAB chroma
  edit in both directions. Levels: definition (b), equal steps in corpus
  SD solved per scene, at +-1/3, +-2/3 and +-1 SD on both features, so
  the unedited original sits in the middle of both ladders and 'edited'
  points both ways. No clipping budget: the upward contrast levels clip
  (reported, not used to cap or exclude), and the +3 images were judged
  acceptable. All 47 v4 scenes, none set aside, for variety. No grid
  block in v5.

6. PLAIN-LANGUAGE SUMMARY
------------------------------------------------------------------------
  This folder is the v5 stimulus set: 47 scenes, each in 49 versions,
  2,303 images of 512 x 512 px. Every scene's unedited photograph is the
  middle cell, with three contrast levels below and three above it
  (about 0.33, 0.67 and 1 corpus SD) crossed with three colour levels
  below and three above.

  Every image is byte-identical to the image of the same cell in test
  run 4aa278d54d, so the visual check and the CLIP results of that run
  apply to this set unchanged.

  On the two ladders through the original, every colour level is within
  0.002 SD of its target and every contrast level within 0.049 SD (77 of
  282 contrast levels miss by more than 0.01 SD). Where both features
  are edited, the colour edit's effect depends on the contrast edit
  before it, so those cells sit up to 0.51 SD from the nominal colour
  level. The trial-design scripts use each image's measured values.

  The upward contrast levels clip: in the typical scene c+1 7%, c+2 15%,
  c+3 27% of pixels (worst scene 64%). This was accepted: it is
  reported, never used to cap a level or drop an image.

  Checks not passed: T3 (WARN). The source photographs are not included;
  sources.csv gives each one's Places365 file ID and SHA-256, so the set
  can be rebuilt from the dataset with the copy of the script in
  provenance/.
